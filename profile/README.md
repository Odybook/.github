# Odybook

![Odybook Banner](odybook_banner_sketchbook.png)

The modern operating system and white-label storefronts for tour operators and travel agencies.

## Ecosystem

- **[odybook-web](https://github.com/Odybook/odybook-web)**: Multi-tenant booking engine, CRM, operations dashboard, and Stripe Connect payments.
- **[odybook-sites](https://github.com/Odybook/odybook-sites)**: High-performance multi-tenant storefront engine with dynamic OKLCH theming and travel journals.
- **[odybook-ops](https://github.com/Odybook/odybook-ops)**: Autonomous operations, AI copilot, and multi-agent coordination pipelines.
- **[odybook-mcp](https://github.com/Odybook/odybook-mcp)**: Model Context Protocol (MCP) server for agentic commerce and tool integration.

Based in Paris. Powered by Next.js 16, React 19, Supabase, and Stripe.
